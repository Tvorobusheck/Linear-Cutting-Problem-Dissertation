%% 5.3.3 В заключении диссертации излагают итоги выполненного исследования, рекомендации, перспективы дальнейшей разработки темы.
%% 9.2.3 В заключении автореферата диссертации излагают итоги данного исследования, рекомендации и перспективы дальнейшей разработки темы.
\begin{enumerate}
  \item Разработана модель интегрированного плана выпуска тамбуров, их~нарезки и~расписания работы оборудования. Модель учитывает характеристики заказов, ограничения БДМ и~ПРС/БРС, доступность полуфабрикатов, динамику складских состояний, сроки исполнения и~принадлежность оборудования одному производственному помещению.

  \item Предложены точный метод полного перебора для~задач малой размерности и~приближённый метод на~основе генетического поиска. Конструктивные процедуры формируют взаимосвязанные компоненты допустимого плана; при~мутации планов нарезки пересчитываются выпуск и~расписание. Получены оценки вычислительной сложности методов.

  \item Разработана дискретно-событийная модель исполнения фиксированного расписания при~случайных отклонениях длительностей операций, отказах и~ремонтах оборудования. Она позволяет оценивать сроки, запаздывание заказов, блокировки и~загрузку ресурсов. Сформулирован порядок сценарного сравнения допустимых планов после завершения детерминированного поиска; текущая программная реализация оценивает один сформированный план.

  \item Программный комплекс реализует численные методы и~имитационную оценку на~языке Python, предоставляет консольный и~графический интерфейсы и~поддерживает форматы CSV и~Excel. На~четырёх небольших тестовых экземплярах значения целевой функции генетического поиска совпали с~результатами полного перебора; на~наибольшем из~них время расчёта сократилось приблизительно в~$59$~раз.

  \item На~производственном экземпляре, содержащем $45$ типов заказов и~$532$ рулона, получен допустимый план; выполнены $10$ имитационных прогонов для~оценки его устойчивости. Результаты подтверждают возможность построения и~исследования плана данного масштаба, но~не~дают гарантий исполнения без нарушений при~любых случайных воздействиях.
\end{enumerate}

Дальнейшие исследования могут быть направлены на~автоматизацию сценарного сравнения нескольких планов, калибровку моделей случайных факторов по~производственным данным, учёт неопределённости непосредственно при~поиске решения и~параллельное выполнение вычислений.
