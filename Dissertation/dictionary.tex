\chapter*{Словарь терминов}             % Заголовок
\addcontentsline{toc}{chapter}{Словарь терминов}  % Добавляем его в оглавление

% В данном словаре собраны ключевые понятия и сокращения,
% используемые в работе. Каждая запись состоит из термина и его определения.

\textbf{БДМ (бумагоделательная машина)} : оборудование для производства бумажного полотна (тамбуров, мастер-рулонов) из целлюлозной массы; характеризуется шириной выпускаемой продукции, скоростью производства и временем смены плотности.

\textbf{БРС (бобино‑резательный станок)} : разновидность продольно‑резательного станка, предназначенная для нарезки небольших рулонов («малых» заказов) на основе мастер‑рулонов, полученных после первой стадии раскроя.

\textbf{Заказ} : требование на изготовление определённого количества рулонов заданной ширины, марки бумаги, её плотности, количества слоёв и срока исполнения.

\textbf{ЗЛР (задача линейного раскроя)} : классическая задача комбинаторной оптимизации, состоящая в разрезании заготовок фиксированной длины (ширины) на части заданных размеров с минимизацией отходов; в настоящей работе рассматривается в контексте целлюлозно‑бумажного производства.

\textbf{Кромка} : технологический отступ с обеих сторон тамбура, который необходимо срезать при раскрое.

\textbf{Марка бумаги} : класс (бренд) бумаги, характеризующий состав и технологию производства; смена марки на БДМ требует дополнительного времени.

\textbf{Переналадка (перестановка ножей)} : изменение конфигурации ножей на ПРС при переходе между раскроями.

\textbf{План выпуска тамбуров} : последовательность тамбуров, которые должны быть произведены на одной БДМ.

\textbf{План нарезки} : последовательность раскроев для одного ПРС; каждый раскрой содержит набор форматов и соответствующие мастер‑рулоны.

\textbf{Плотность (граммаж)} : масса бумажного полотна на единицу площади (г/м²).

\textbf{ПРС (продольно‑резательный станок)} : станок, который разрезает бумажный тамбур на конечные рулоны согласно плану раскроя; задаётся максимальной шириной обрабатываемого тамбура, количеством ножей, скоростью нарезки и временем перестановки ножей.

\textbf{Раскрой} : организация нарезки тамбура на рулоны; определяется набором форматов (ширин) и последовательностью их расположения на станке.

\textbf{Расписание} : упорядоченный список производственных операций, определяющий расписание работы оборудования; обеспечивает согласование плана выпуска тамбуров и плана нарезки во времени.

\textbf{Склад (склады рулонов)} : хранилище для полуфабрикатов (тамбуров для ПРС и рулонов для БРС), ограниченное по вместимости и допустимой ширине; используется для временного хранения между производством и раскроем.

\textbf{Промежуточный рулон для~БРС} : рулон, получаемый в~результате нарезки тамбура на~ПРС и служит полуфабрикатом для~дальнейшей нарезки на~БРС.

\textbf{Тамбур (мастер-рулон)} : рулон, получаемый на БДМ; служит полуфабрикатом для последующей продольной резки.

\textbf{Формат} : рулон, получаемый на ПРС и БРС. Является частью раскроя. Может быть заказом или полуфабрикатом для дальнейшей обработки на БРС.

\textbf{Цех} : производственное помещение, в котором находится оборудование (ПРС, БРС, БДМ, склады).
