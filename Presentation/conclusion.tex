\begin{frame}
    \frametitle{Основные результаты работы (1/2)}
    \small
    \begin{enumerate}
        \item Разработана модель интегрированного плана выпуска тамбуров, нарезки и~расписания оборудования с~учётом характеристик заказов, ограничений БДМ и~ПРС/БРС, полуфабрикатов, складских состояний, сроков и~размещения оборудования в~одном помещении.
        \item Предложены точный метод полного перебора и~приближённый метод на~основе генетического поиска. Конструктивные процедуры формируют взаимосвязанные компоненты допустимого плана; при~мутации нарезки пересчитываются выпуск и~расписание.
    \end{enumerate}
\end{frame}

\begin{frame}
    \frametitle{Основные результаты работы (2/2)}
    \small
    \begin{enumerate}
        \setcounter{enumi}{2}
        \item Разработана дискретно-событийная модель исполнения фиксированного расписания при~отклонениях длительностей операций, отказах и~ремонтах оборудования для~оценки сроков, запаздывания заказов, блокировок и~загрузки ресурсов. Сформулирован порядок сценарного сравнения планов; текущая программа оценивает один план.
        \item Программный комплекс реализует численные методы и~имитационную оценку на~языке Python, предоставляет консольный и~графический интерфейсы, поддерживает форматы CSV и~Excel. На~четырёх тестовых экземплярах значения целевой функции совпали с~результатами полного перебора; на~крупнейшем время расчёта сократилось примерно в~$59$~раз.
        \item На~производственном экземпляре из~$45$ типов заказов и~$532$ рулонов получен допустимый план; выполнены $10$ имитационных прогонов. Результаты подтверждают возможность исследования плана данного масштаба, но~не~гарантируют исполнения без нарушений при~любых случайных воздействиях.
    \end{enumerate}
\end{frame}

\begin{frame}
    \frametitle{Соответствие паспорту специальности 1.2.2}
    \small
    \begin{itemize}
        \item \textbf{п.~1:} разработка новых методов математического моделирования; трёхкомпонентная модель интегрированного плана производства, раскроя и расписания.
        \item \textbf{п.~2:} разработка, обоснование и тестирование вычислительных методов; полный перебор и генетический поиск.
        \item \textbf{п.~3:} реализация численных методов в виде комплекса программ.
    \end{itemize}
\end{frame}

\begin{frame}

        \item \textbf{п.~8:} комплексное исследование задачи с применением математического моделирования и вычислительного эксперимента.

\begin{frame}
    \frametitle{Научная новизна (1/2)}
    \small
    \begin{enumerate}
        \item Разработан метод математического моделирования производственных планов и~расписаний, представленных трёхкомпонентной структурой: планом производства тамбуров, планом раскроя и~расписанием производственных операций.
        \item Предложена модель согласования производства и~раскроя для цепочки БДМ, склад, ПРС/БРС с~учётом динамики складов, доступности полуфабрикатов, сроков заказов и~технологических ограничений, включая размещение оборудования в~одном производственном помещении.
    \end{enumerate}
\end{frame}

\begin{frame}
    \frametitle{Научная новизна (2/2)}
    \small
    \begin{enumerate}
        \setcounter{enumi}{2}
        \item Разработан численный метод на~основе генетического алгоритма для~поиска допустимых интегрированных планов с~согласованным пересчётом производства и~расписания при~изменении раскроя.
        \item Разработана дискретно-событийная имитационная модель производственного расписания, учитывающая отклонения длительностей операций, отказы и~ремонты оборудования и~позволяющая оценивать устойчивость плана. Сформулирован метод сравнения допустимых планов.
    \end{enumerate}
\end{frame}
