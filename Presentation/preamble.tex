\begin{frame}
    \frametitle{Положения, выносимые на защиту}
    \small
    \begin{enumerate}
        \item Система дискретно-событийного имитационного моделирования исполнения расписания для оценки устойчивости планов при отклонениях длительностей операций и отказах оборудования.
        \item Математическая модель интегрированного плана производства, раскроя и~расписания, учитывающая технологические, временные и~складские ограничения.
        \item Численный метод решения задачи формирования производственного расписания с~учётом плана раскроя рулонов бумажного полотна.
        \item Комплекс программ для автоматизированного формирования производственных расписаний с~учётом планов раскроя рулонов бумажного полотна.
    \end{enumerate}
\end{frame}
\note{
    Формулировки соответствуют четырём положениям из общей характеристики работы.
    Имитационная оценка выполняется после детерминированного поиска плана;
    базовая программная реализация оценивает один сформированный план.
}

\note{
    Работа состоит из четырёх глав.

    \medskip
    В первой главе проводится обзор литературы по задаче линейного раскроя и~смежным постановкам, описывается технологический контекст целлюлозно-бумажного производства и~формулируется постановка задачи.

    Во второй главе введены глобальный план, целевая функция и~десять ограничений, а~также дискретно-событийная модель исполнения расписания и~порядок сценарной оценки устойчивости.

    Третья глава посвящена полному перебору, генетическому поиску и~процедурам формирования согласованных планов и~расписания.

    В четвёртой главе представлены программный комплекс, его тестирование и~эксперименты на тестовых и производственных данных.
}
